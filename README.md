## Installation
1. **Grab the latest compressed file from the release section.**
   [Latest Release](https://github.com/Djalcoding/Gallide/releases/latest)

3. **Run this inside the unzipped directory** :
```
./install.sh # This will install gallide to your system
```
3. **Add this to your .bashrc**
```
eval "$(gallide --init)" # This will enable the g alias
```
