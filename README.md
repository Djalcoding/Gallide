<h1>Gallide</h1> 
Gallide is a TUI(Terminal-based User Interface) designed to make navigating directoires with the <code>cd</code> command more intuitive.<br></br>
instead of constantly typing <code>cd</code>, <code>ls</code> and <code>clear</code> to navigate your files, you now have to write a single command : <code>g</code>
